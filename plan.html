Teacher portfolio build plan

Four weeks.
Four focused sessions.

The sequence

Build the foundation, then add evidence.

Start with the current About page and complete one session before starting the next.

01

Week one / foundation

Make the site feel like a portfolio.

Give visitors a clear path through the information already on the page.

  1. 01

    Session 1

    Create the portfolio's main structure

    • Build: Add a “Skip to content” link, a simple menu, and a Projects section.
    • Use: Show “projects coming soon” until real project facts are ready.
    • Done: Every menu link works and no project claims have been invented.

02

Week two / browse

Make projects easy to explore.

Turn approved project information into a consistent set of project cards.

  1. 02

    Session 2

    Create project cards from one list

    • Build: Keep project information in one simple list.
    • Use: Let the page create matching project cards from that list.
    • Done: Changing a project in one place updates its card.

03

Week three / evidence

Show the thinking behind the work.

Let visitors understand one project without leaving the page.

  1. 03

    Session 3

    Open a project for more details

    • Build: Add a larger view for one selected project.
    • Show: Include its context, goal, process, evidence, and reflection.
    • Done: It opens and closes with a mouse or keyboard and returns to the same card.

04

Week four / release

Make it ready to share.

Check the important basics and put the finished page online.

  1. 04

    Session 4

    Check it and publish it

    • Check: Test the page on a phone and computer with a keyboard.
    • Publish: Put it online with GitHub Pages, GitHub’s built-in website hosting.
    • Done: The online page matches the tested local page and has no error messages.
